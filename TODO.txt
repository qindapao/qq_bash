[P2.5] 敌弹按 cd 分桶，跳过空转（**明天必做，别漏**）
  现状：每 tick 遍历 EB_N 个槽，即便这发本 tick 不移动（110 发里约 3/4 不动），

  预期：110 发时再省 1.5–2.5ms；实现时注意：桶只是索引表，槽位与 EB_* 数组
  仍是唯一数据源（死亡时从桶里摘除，避免悬挂索引）。
  验收：四个场景逐格一致 + tick 基准不低于当前 17–18ms + 桶索引与 EB_ALIVE 一致
  （加一条断言：任一时刻所有桶的并集 == 存活且本 tick 会动的槽集合）。

x.in
    * 性能优化
        *. 从 children 数组中找 token 的数字索引不需要先把它转换成数组然后再找，可以考虑使用类似下面
            这种方法，效率非常高
            https://github.com/akinomyoga/ble.sh/blob/master/src/util.sh
            ## @fn ble/string#last-index-of text needle [n]
            ##   @param[in] text
            ##   @param[in] needle
            ##   @param[in] n
            ##     この引数を指定したとき n 番目の一致を検索します。
            ##   @var[out] ret
            function ble/string#last-index-of {
              local haystack=$1 needle=$2 count=${3:-1}
              ble/string#repeat '"$needle"*' "$count"; local pattern=$ret
              builtin eval "local transformed=\${haystack%$pattern}"
              if [[ $transformed == "$haystack" ]]; then
                ret=-1
              else
                ret=${#transformed}
              fi
              ((ret>=0))
            }
            当前由于token是Q字符串，所以如果夹带了索引，要一起寻找匹配Q字符串+ID。
    * 边缘BUG排查
        * 脏键/丢键审计（灾备预案）：
            目前未发现异常，暂不实现。未来出现玄学问题（如内存泄漏、找不到节点）时启用。

            【实现方式】独立封装为 x_verify_tree 函数，严禁修改 x_walk 本身！
            函数内调用 x_walk 做一次从根节点的全量遍历，同时统计访问到的有效 KV 数量。

            【计数规则（极易写错，必须对称）】
            遍历回调中，对每个节点精确累加：
                节点自身的存在感     +1
                节点 .t (类型)      +1 (若有)
                节点 .k (物理路径)   +1 (若有，叶子)
                节点 .s (子节点列表) +1 (若有，容器)
                节点 .c.{key} 映射  +1 (遍历 .s 里的对象键，每个算 1)
            遍历结束后，手动补上未被 x_walk 遍历到的内部键：
                根节点的 .t         +1
                max_index           +1

            【比对逻辑】
            若 统计总数 != ${#tree[@]} ，说明存在“幽灵键”或“孤儿映射”，直接 die 报错。

            【调用时机（信任点主动调用，严禁进热路径）】
            1. 游戏存档 (save_game) 之前 / 读档重建之后。
            2. 测试用例 (test.sh) 的收尾阶段。
            3. x_init 初始化一个复杂的类对象之后。

        * 弯月子弹：单格的弯月子弹和多格的，unicode也可以利用。多出现在boss的子弹类
          中。
        * 跟踪导弹
            跟踪导弹用Mixin来注入。跟踪导弹要设置燃料，不能一直追，可以由普通的导弹
            升级，比赛吃到两个m就变成跟踪导弹，再吃一个变成2股跟踪，被击中减少股数。
            和普通子弹类似。跟踪导弹最多两股。
        * 不同的子弹击中效果，包括导弹。
        * 集簇炸弹2号。其实是毁灭冲击波。效果是从飞机的中心坐标点开始，从内玩外
            扩展的圆，碰到的子弹全部消失，接触到的敌人受到20点伤害。
    * BOSS类
        * 五角星旋转飞盘
            效果是变换动作旋转靠近玩家。发射子弹同时撞击玩家。
        * 八个方向飞行的1000HP的巨型母舰，产生小飞碟。
            自己有炮，小飞碟也有炮。
