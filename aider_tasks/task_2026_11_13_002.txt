任务：主循环架构重构（逻辑时钟与渲染时钟解耦）

【核心问题】
当前主循环里，所有移动、冷却、生成、碰撞都在"每帧执行一次"。
导致游戏速度绑定渲染帧率：机器快则游戏快，机器慢则游戏慢。

【目标】
把主循环拆成三段：
1. 采样时间 → ACC_US（累加器已有，保留）
2. 每帧读输入 → 只记录意图（dx/dy/fire 等 flag）
3. 执行 N 次逻辑 tick（N = ACC_US / TICK_US），所有移动/冷却/生成/碰撞都在 tick 内部
4. 渲染 → 每帧执行

【严格约束】
- 所有"每帧减 1"的冷却变量（fire_cd、missile_cd、inv、敌人/Boss 的 cd）改成"每 tick 减 1"。
- 所有 move / 生成 / 碰撞逻辑，从主循环体搬进 tick 内部。
- 输入采样频率保持高频（5ms 超时），不要被 tick 频率拖慢。
- 不要在 tick 里做任何渲染动作（渲染留到外面每帧一次）。
- 保留 DEC_TICKS 上限 100，防止电脑卡顿时积压太多 tick。

【完整性检查清单（改完必须逐项核对）】
1. 冷却变量：确认以下所有变量都是"每 tick 减 1"，不是"每帧减 1"：
   - 主循环：fire_cd, missile_cd, inv
   - Boss 对象：{cd}
   - 敌人对象：{cd}
   - 玩家对象：{t2}, {t3}, {t4}, {t5}, {mt}, {lt}, {st}
   - 注意：对象内部的 {cd} 是在 move 方法里 +1 的，只要 move 在 tick 里调用，它们自动正确。请确认 move 调用确实在 tick 内。
2. move 调用：确认以下 6 类对象的 xo_call move 都在 tick 内部：
   子弹 BULLETS、导弹 MISSILES、敌人子弹 ENEMY_BULLETS、敌人 ENEMIES、掉落物 DROPS、飘字 WORDS。
3. 频率计数器：enemy_tick / drop_tick / word_tick 的 ++ 必须在 tick 内。
4. 碰撞检测：确认以下 5 类碰撞检测都在 tick 内：
   子弹 vs 敌人、导弹 vs 敌人、敌人子弹 vs 玩家、敌人 vs 玩家、掉落物 vs 玩家。
5. 输入采样：必须留在"每帧一次"的位置，超时 5ms，不能放进 tick。
6. 渲染相关：CLEAR_BATCH、render()、render_bomb_fx()、render_boss_death() 必须留在 tick 外，每帧一次。

【语义细节避坑指南（极易忽略）】
1. "每 tick 减 1"的精确含义：跑 N 个 tick 就递减 N 次。如果一帧追上了 3 个 tick，fire_cd 应该减 3，不是减 1。
2. want_bomb 是"一次性触发"，绝对不能放进 tick 循环里：一帧跑 3 个 tick 会引爆 3 次炸弹。want_bomb 的处理块必须留在帧循环里，只执行一次。
3. CLEAR_BATCH 是"tick 里填，帧里消费"：Bullet_move 等 move 方法在 tick 里往 CLEAR_BATCH 里 push 擦除坐标。但 CLEAR_BATCH 的清空和输出必须在帧循环里做一次。
4. 暂停时必须重置 LAST_US：暂停时 continue 会导致 ACC_US 在恢复瞬间累积成 100 tick 爆发。暂停的 continue 之前加一句 LAST_US=${EPOCHREALTIME/./}。
5. local -n 的绑定不要搬进 tick 循环：保留在帧循环里绑定一次、tick 里复用、帧循环末尾释放。每 tick 重新绑定反而降低性能。
6. 以下变量保持"帧相关"，不要搬进 tick：hud_tick、bomb_fx_tick、BOSS_DEATH_TICK、msg_tick、paused / paused_drawn。这些是"视觉帧"概念。
7. 奖励计时器 {t2}{t3}{t4}{t5}{mt}{lt}{st} 已经在用 DEC_TICKS 递减了：迁移时不要重复递减。从现有位置搬到 tick 内部，每 tick 减 1，而不是保留现有的 DEC_TICKS 递减 + 额外再加 tick 内递减。
8. 输入意图（dx dy）每个 tick 消费一次是正确的：如果一帧跑了 3 个 tick，玩家向左移动 3 格，符合真实时间。不要把 dx dy 只在第一个 tick 消费、后面清零。

【验收】
同一台机器上，把 FPS 从 50 改成 30 再改成 100，游戏内的子弹速度、Boss 移动速度、奖励持续时间应完全一致。
